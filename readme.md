# Purpose of the application

The purpose of this application is to test SSE concept and implement it in a mini project using the following stack:
- Nextjs
- FastAPI
- SQLalchemy
- Postgres


# Architecture of the application

A single docker compose file to run the application at once.

The application will contain :
 - UI 
 - Backend 
 - Postgres DB to store the data 
 - PGadmin to show the DB 

Later if i want i can include following services for better learning:
- Keycloak
- Celery (if needed)
